# 设计规范

## 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#1A1A1A` | 深黑灰色，主面板和全屏背景 |
| 面板背景 | `#2D2D2D` | 略浅灰，卡片/输入区底色 |
| 文字-未读 | `#FFFFFF` | 纯白 |
| 文字-正在读 | `#FFFFFF` + 下划线 `#4A90D9` | 白色文字 + 蓝色底部下划线 |
| 文字-已读 | `rgba(255,255,255,0.3)` | 白色 30% 透明度 |
| 主按钮-开始 | `#4A90D9` | 蓝色，启动全屏提词 |
| 主按钮-语音 | `#E05A5A` | 红色，开关语音跟随 |
| 次要按钮 | `#5A5A5A` | 灰色 |
| 滑块轨道 | `#3A3A3A` | 深灰 |
| 滑块填充 | `#4A90D9` | 蓝色 |
| 文本输入区边框 | `#444444` | 灰边框 |
| 悬浮控制条背景 | `rgba(0,0,0,0.7)` | 半透明黑 |

| 用途 | 字体 | 大小范围 |

| UI 标签 | PingFang SC | 13pt |

## 悬浮控制条（全屏底部）

- 高度：约 60px
- 背景：`rgba(0,0,0,0.7)`
- 圆角顶部：8px
- 显示逻辑：鼠标移动到屏幕底部 80px 区域时滑入，3 秒无操作后滑出
- 控件间距：均匀分布，图标 + 文字标签
- 语音跟随指示：开启时红色脉冲指示灯

## 交互细节

1. **按钮悬停**：颜色加深 10%，鼠标变手型
2. **滑块拖动**：实时预览（全屏模式文字即时变化）
3. **开始提词**：主面板隐藏/最小化，全屏窗口弹出
4. **退出全屏**：按 ESC 或点击退出按钮，回到主面板
5. **窗口最小尺寸**：主面板 800×600，全屏自适应屏幕分辨率

## 动画

- 控制条滑入/滑出：200ms ease
- 滚动：无动画（QTimer 逐帧刷新，保证流畅）
- 文字透明度过渡：当前行到下划线强调时 150ms 渐显
