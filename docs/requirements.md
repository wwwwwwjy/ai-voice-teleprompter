# 需求规格说明书

## 项目名称

Mac 语音提词器（Teleprompter with Voice Following）

## 版本

v1.0

---

## 功能需求

### FR-1 文本输入与管理

| ID | 需求 | 优先级 | 细节 |
|----|------|--------|------|
| FR-1.1 | 粘贴文本 | P0 | 支持粘贴中文、英文、数字及各类字符 |
| FR-1.2 | 保存文本 | P1 | 保存为 .txt 文件到本地 |
| FR-1.3 | 加载文本 | P1 | 打开本地 .txt 文件加载到编辑器 |

### FR-2 全屏文字显示

| ID | 需求 | 优先级 | 细节 |
|----|------|--------|------|
| FR-2.1 | 全屏模式 | P0 | 文字铺满整个屏幕，黑色背景 |
| FR-2.2 | 平滑滚动 | P0 | 文字连续缓慢向上滚动，类似电影片尾字幕 |
| FR-2.3 | 滚动速度可调 | P0 | 滑块或 +/- 按钮调节速度 |

### FR-3 文字格式调节

| ID | 需求 | 优先级 | 细节 |
|----|------|--------|------|
| FR-3.1 | 字体大小 | P0 | 可放大缩小，全屏模式下也可调节 |
| FR-3.2 | 文字粗细 | P1 | 常规 / 加粗切换 |
| FR-3.3 | 每行字数 | P1 | 控制一行显示多少个字（调节文本框宽度） |

### FR-4 文字状态显示

| ID | 需求 | 优先级 | 细节 |
|----|------|--------|------|
| FR-4.1 | 未读文字 | P0 | 白色显示 |
| FR-4.2 | 正在读的文字 | P0 | 白色高亮，底部下划线标识当前位置 |
| FR-4.3 | 已读文字 | P0 | 灰色或降低透明度（建议透明度 40%） |

### FR-5 语音识别

| ID | 需求 | 优先级 | 细节 |
|----|------|--------|------|
| FR-5.1 | 麦克风输入 | P0 | 调用 Mac 内置麦克风 |
| FR-5.2 | 离线识别 | P0 | 使用本地 Vosk 模型，不调云端 API |
| FR-5.3 | 中英混读 | P0 | 主要中文，偶尔英文，模型需支持中英文 |

### FR-6 语音跟随

| ID | 需求 | 优先级 | 细节 |
|----|------|--------|------|
| FR-6.1 | 实时跟随 | P0 | 识别到文字后自动定位到对应位置 |
| FR-6.2 | 按字变淡 | P0 | 读到哪个字，哪个字透明度降低 |
| FR-6.3 | 跟随开关 | P0 | 一键开/关语音跟随，红色按钮 |

### FR-7 智能跳段

| ID | 需求 | 优先级 | 细节 |
|----|------|--------|------|
| FR-7.1 | 跳段检测 | P1 | 识别到读者跳过超过 5 个字时自动跳转 |
| FR-7.2 | 防误判 | P1 | 避免因识别错误导致的乱跳，需稳定判断 |

### FR-8 UI 设计

| ID | 需求 | 优先级 | 细节 |
|----|------|--------|------|
| FR-8.1 | 主面板 | P0 | 参考用户提供的截图布局 |
| FR-8.2 | 配色 | P0 | 黑色背景 + 灰色面板 + 白色文字 |
| FR-8.3 | 按钮颜色 | P0 | 蓝色按钮 → 开始全屏提词；红色按钮 → 开启语音跟随 |
| FR-8.4 | 全屏控制条 | P0 | 半透明悬浮条，包含字体、粗细、字数、速度、跟随开关 |
| FR-8.5 | 简洁直观 | P0 | 不堆砌功能，核心控件突出 |

### FR-9 非功能性需求

| ID | 需求 | 细节 |
|----|------|------|
| NFR-1 | 纯本地运行 | 不依赖网络 |
| NFR-2 | 轻量化 | 内存占用 < 500MB，模型文件 < 100MB |
| NFR-3 | 打包为 .app | 双击即可运行，无需安装 Python |

---

## 用户故事

1. 作为演讲者，我希望把稿子粘贴进去，全屏看到大字滚动，这样我演讲时不用低头看稿。
2. 作为朗诵者，我希望软件能听到我读到哪里，自动跟上我的节奏，不要我手动翻页。
3. 作为使用者，如果我即兴跳过了一段，希望软件自动识别并跳到我在读的地方。
