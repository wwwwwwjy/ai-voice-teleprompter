## 步骤 1：项目初始化与环境搭建

**目标**：创建项目骨架、虚拟环境、依赖安装、验证可运行

**任务**：
- [ ] 创建 `src/`、`src/ui/`、`src/core/`、`src/speech/`、`src/utils/` 目录
- [ ] 创建 `requirements.txt`
- [ ] 创建虚拟环境并安装依赖
- [ ] 下载 Vosk 中文小模型到 `models/`
- [ ] 编写 `main.py` 入口（显示一个空白 PyQt6 窗口验证环境）
- [ ] 运行验证

**验证标准**：运行 `python src/main.py` 能看到一个空白窗口

---

## 步骤 2：主窗口 UI — 控制面板

**目标**：实现主面板完整 UI（先不做功能逻辑）

**任务**：
- [ ] 实现顶部工具栏（打开、保存、粘贴按钮）
- [ ] 实现设置区域（字体大小滑块、粗细切换、每行字数滑块、滚动速度滑块）
- [ ] 实现蓝色"开始全屏提词"按钮
- [ ] 实现红色"开启语音跟随"按钮
- [ ] 实现文本编辑区（QTextEdit / QPlainTextEdit）
- [ ] 应用设计规范中的配色

**验证标准**：运行后看到完整主面板，按钮可点击（暂无功能），配色符合设计规范

---

## 步骤 3：全屏提词窗口 — 文字显示与滚动

**目标**：全屏显示文字并支持平滑滚动

**任务**：
- [ ] 创建全屏窗口类，黑色背景
- [ ] 实现文字排版（根据每行字数拆分文本）
- [ ] 使用 QPainter 手动绘制文字，支持透明度
- [ ] 实现平滑滚动引擎（QTimer 定时刷新）
- [ ] 滚动速度可调
- [ ] 已读/正在读/未读三种状态的文字绘制
- [ ] 主窗口"开始全屏提词"按钮连接全屏窗口

**验证标准**：点击蓝色按钮进入全屏，文字自动滚动，按 ESC 退出

---

## 步骤 4：全屏悬浮控制条

**目標**：全屏模式下可调节参数

**任务**：
- [ ] 底部半透明悬浮条 UI
- [ ] 字体大小 +/- 按钮
- [ ] 粗细切换按钮
- [ ] 每行字数 +/- 按钮
- [ ] 滚动速度 +/- 按钮
- [ ] 语音跟随开关按钮（红色）
- [ ] 退出全屏按钮
- [ ] 鼠标靠近底部显示、3秒无操作隐藏的动画

**验证标准**：全屏模式下鼠标移到底部出现控制条，可调节参数即时生效

---

## 步骤 5：文件读写与配置持久化

**目标**：支持保存/加载 txt 文件，记住用户设置

**任务**：
- [ ] 实现打开 .txt 文件功能
- [ ] 实现保存 .txt 文件功能
- [ ] 实现配置读写（JSON 文件存储：字体大小、粗细、每行字数、速度）
- [ ] 启动时自动加载上次配置
- [ ] 文本编辑区内容随加载/粘贴更新

**验证标准**：打开文件显示在编辑区，保存后再打开内容一致，重启软件设置保留

---

## 步骤 6：语音识别集成（Vosk）

**目标**：接入 Vosk 离线语音识别

**任务**：
- [ ] 封装 Vosk 模型加载
- [ ] 使用 sounddevice 捕获麦克风音频流
- [ ] 实时获取识别结果
- [ ] 在主窗口显示识别到的文字（调试用，方便验证）
- [ ] 添加麦克风权限请求

**验证标准**：点击开始识别，对着麦克风说话，界面实时显示识别文字

---

## 步骤 7：语音跟随与智能跳段

**目标**：识别文字自动匹配文档位置，控制滚动和文字状态

**任务**：
- [ ] 实现模糊文本匹配算法（识别文字 → 文档位置）
- [ ] 当前朗读位置指针更新
- [ ] 已读文字透明度降低逻辑
- [ ] 当前行高亮显示逻辑
- [ ] 智能跳段检测（> 5 字偏移 → 确认 → 跳转）
- [ ] 防抖机制（连续 2 次确认才跳）
- [ ] 跟随开关控制识别启停
- [ ] 全屏控制条上的跟随状态指示

**验证标准**：开启语音跟随后朗读文字，光标跟随移动，已读文字变淡，跳段自动定位

---

## 步骤 8：整合测试与问题修复

**目標**：全流程测试，修复 bug

**任务**：
- [ ] 完整流程测试：粘贴文字 → 全屏 → 语音跟随 → 朗读 → 跳段
- [ ] 边缘情况测试：空文本、超长文本、特殊字符
- [ ] 性能测试：长时间运行、内存占用

**验证标准**：所有功能正常，无明显 bug，长时间运行稳定
